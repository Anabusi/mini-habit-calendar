Мини-календарь привычек — прототип

Внутри:
- index.html — приложение
- manifest.json — параметры установки как PWA
- sw.js — кэширование для офлайн-работы после первого открытия

Как попробовать:
1. Откройте index.html в браузере на компьютере, чтобы посмотреть прототип.
2. Для установки на Android и офлайн-работы после первого открытия приложение нужно разместить на HTTPS-хостинге (например, GitHub Pages).
3. Данные хранятся локально в браузере на устройстве. Экспортируйте резервную копию кнопкой «Экспорт данных».

Важно:
- Это прототип, а не опубликованное приложение из Google Play.
- Не очищайте данные сайта/браузера без экспорта резервной копии.
- Для импорта резервной копии используйте JSON-файл, созданный кнопкой «Экспорт данных».
